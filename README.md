# GetWeatherApp
This App is made by Android Studio, so this app can only run on Android platform.
Ways to run it on your computer:
1. download Android Studio and set up all the environment, sdk, platform-tools, etc.
2. download the zip file and open it in the Android Studio.
3. 4. If everything is fine, click run and open the emulator, then you should see the app running on your emulator.
5. I am not sure if the LLM could work on your computer. If not, you might need to go to https://www.volcengine.com/ to sign up and refer to the instructions to set up the environment and change the api key in my code to your own api key
6. Enjoy it.
