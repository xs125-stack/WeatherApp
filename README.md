# GetWeatherApp
This App is made by Android Studio, so this app can only run on Android platform.
Ways to run it on your computer:
1. download Android Studio and set up all the environment, sdk, platform-tools, etc.
2. download the zip file and open it in the Android Studio.
3. Solve configuration problems, if you meet problems, please refer to this webstie: https://blog.csdn.net/weixin_39220472/article/details/79947295?ops_request_misc=%257B%2522request%255Fid%2522%253A%2522a0cf952c8f4d716c28c9f659238658dc%2522%252C%2522scm%2522%253A%252220140713.130102334.pc%255Fall.%2522%257D&request_id=a0cf952c8f4d716c28c9f659238658dc&biz_id=0&utm_medium=distribute.pc_search_result.none-task-blog-2~all~first_rank_ecpm_v1~rank_v31_ecpm-4-79947295-null-null.142^v102^pc_search_result_base6&utm_term=andriod%20studio%E8%B8%A9%E7%9A%84%E5%9D%91&spm=1018.2226.3001.4187
4. If everything is fine, click run and open the emulator, then you should see the app running on your emulator.
5. I am not sure if the LLM could work on your computer. If not, you might need to go to https://www.volcengine.com/ to sign up and refer to the instructions to set up the environment and change the api key in my code to your own api key
6. Enjoy it.

Details:
1. The Weather information come from Open Weather 3.0 One Call API
2. The LLM Function is achieved by integrating Doubao LLM API
3. Mainly Java programming
